# Macross 30 — English setup guide

**[Download the Windows launcher](https://github.com/saintiron82/macross30-releases/releases/download/v0.3.1/Macross30-launcher-0.3.0.zip)**

Game **0.3.1** · Launcher **0.3.0** · Windows x64 test release.

## Install and play

1. Download `Macross30-launcher-0.3.0.zip` and extract it to a folder.
2. Run `Macross30Launcher.exe`. No separate Python, Node.js, browser engine or C++ build tools are needed for the launcher.
3. Choose **English** as your play language. The launcher display language and game language are separate settings.
4. Press **Play/Update** and approve the required downloads. The launcher installs the common program and the selected language pack.
5. For first setup, select the supported Japanese Macross 30 ISO dumped from your own legitimate copy, and follow the installation prompts.
6. Start the game. Existing installations and settings are reused where supported. If you are asked for an installation folder or ISO, choose your own installation and original dump.

The common program package contains a precompiled Windows game executable. Game code is not compiled on the player's PC. Required original data, including the original EBOOT, is prepared locally from the user's ISO. The launcher manages the language pack; do not extract the English pack over an existing installation manually.

## Languages and features

- **English:** available as a separate language pack; translation and display review are ongoing.
- **Korean:** available as a separate language pack.
- **Japanese:** uses the original game data; no Japanese language pack is required.
- Keyboard/gamepad input, remappable controls and FHD/QHD resolution options are supported. Performance depends on hardware, settings and scene.

The launcher and game have separate version numbers. A game update does not necessarily require reinstalling an unchanged language pack.

## Requirements and current limits

Windows 10/11 x64, a Direct3D 12-capable GPU, and an AVX2/SSE4.1-capable CPU are required by the current Windows runtime. First setup needs internet access, sufficient free disk space and your own supported original game dump. The first-time installer may prepare additional extraction tools when needed.

This is a test release. English translation, full-game progression and scene-by-scene graphics checks are still ongoing. Complete first-time installation on a new PC and actual launcher replacement by a future published version remain additional acceptance checks. Do not interpret a successful build or screenshot as full-playthrough validation.
