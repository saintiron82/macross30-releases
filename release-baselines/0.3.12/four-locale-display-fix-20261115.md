한국어 변경은 추가 장비 이름·설명 및 공격명 42개, 일부 무장 구성 안내, 인물 소개와 복장 구분명, 관련 표시문구를 포함한다. `ゴーストブースター`는 `고스트 부스터`로 반영했다. 네 언어가 모두 새 번역을 필요로 했던 것은 아니며, 기존 세 언어의 팩은 그대로 보존했다.

한국어 출력: `final/korean/hud-quest-badges-v21/EBOOT.korean-display-v23.elf`. 기존 v22 파일은 보존하고 active-ui의 ELF 선택만 갱신했다. 런처의 실제 `prepare_localization` 경로가 v23을 선택하며 고스트 부스터와 FAST 팩을 읽는 것까지 확인했다. 실행 중인 게임은 재시작해야 한다. 언어 설정은 변경하지 않았다.

검증은 원본/기반 해시, 정확한 문자열·NUL 여백, 슬롯 바이트 길이, 중간 문자열 포인터 부재, 실행 코드·ELF 헤더 보존, 슬롯 밖 변경 없음, 제어 토큰·줄 수, 현재 한국어 폰트 글리프 범위, 출력 재읽기를 포함한다. 러시아어·스페인어는 설치 manifest의 ELF 팩·번역 원고·폰트 해시와 runtime 레코드의 기준 영어 바이트·번역문·글리프를 확인했다. 변경하지 않은 영어 기준 ELF의 해시도 동결 범위와 일치한다.

곡명과 음악 크레딧은 기존 정책에 따라 원문을 유지했다. 노래 이름이 포함된 일부 복장명과 기술명에서도 곡명 부분을 보존하고 나머지 안내를 번역했다. 이 허용 항목은 일반적인 일본어 잔존 검사와 구분해야 한다. 내부 디버그 문자열은 번역 대상에 넣지 않았다.
