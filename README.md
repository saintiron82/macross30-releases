한국어·영어팩을 제공하며 일본어는 원본 데이터를 사용합니다. 모든 언어에서 실행·렌더링·진행 문제가 있을 수 있으며 제보를 받습니다. 게임 코드를 사용자 PC에서 컴파일하지 않으며, 프로그램팩의 사전 빌드 Windows 실행 파일과 선택 언어팩을 런처가 설치합니다. 원본 EBOOT와 게임 데이터는 사용자 ISO에서 로컬로 준비합니다.

Windows 10/11 x64, D3D12 GPU, AVX2/SSE4.1 CPU가 필요합니다. 런처를 위해 Python이나 브라우저 엔진을 따로 설치할 필요는 없습니다. 테스트 배포이며 원작과 다른 그래픽, 이벤트 미발생·오작동, 미션 진행 정지와 실행·조작·저장·오디오·번역 문제를 제보받습니다.

**본인 소유 정품에서 직접 덤프한 ISO만 사용하세요.** 게임 ISO·원본 EBOOT/ELF와 불법 다운로드 링크는 제공하거나 공유하지 않습니다. 비공식·비상업 팬 프로젝트이며 관련 권리자의 승인이나 제휴를 받은 프로젝트가 아닙니다. 원본 소유가 모든 복제·변경·배포를 자동 허용하는 것은 아닙니다. 관련 법과 이용 조건을 준수하세요. **권리자 요청이나 프로젝트 사정에 따라 사전 예고 없이 언제든 배포가 중단될 수 있습니다.**

## 기존 런처 0.3.0 사용자

1. 런처 하단 **런처 업데이트**를 누르고 교체를 승인하세요.
2. 다시 열린 런처에서 기존 플레이 언어를 선택하고 **업데이트/플레이**를 눌러 게임 수정 파일도 적용하세요.
3. 자동 업데이트에 실패하면 최종 0.3.1 ZIP을 받아 런처를 종료한 뒤 기존 런처 파일을 교체하세요.

기존 게임 설치 폴더와 저장 파일은 삭제하지 마세요. 원본 데이터 복구가 필요하면 기존에 사용하던 본인 소유 ISO를 지정하세요.


런처 0.3.2부터 실행 시 새 런처를 자동으로 다운로드·교체·재시작합니다. 게임 실행 중에는 런처를 유지하고 버튼에 실행 중으로 표시합니다. 기존 0.3.0/0.3.1은 런처 업데이트를 한 번 눌러 0.3.2로 교체하세요. 게임·언어팩 버전은 0.3.1입니다.


게임 종료 후 런처의 **로그 → 마지막 플레이 로그 보내기**에서 내용을 확인하고 전송할 수 있습니다. 로그인 없이 운영진 전용 Discord 채널로 보내며 세이브는 선택 첨부입니다. ZIP은 로컬 bug-reports에 남습니다.
