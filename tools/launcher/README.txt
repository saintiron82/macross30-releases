Macross 30 Launcher 0.2.13

플레이 언어를 고르고 플레이를 누르세요.
새 업데이트가 있으면 한 번 묻습니다. 승인하면 다음 순서로 자동 진행합니다.
1. 기본 게임 패치
2. 선택한 언어 패치
3. 게임 실행
최신 상태라면 바로 실행합니다. 언어를 선택하는 것만으로는 다운로드하지 않습니다.
처음 준비할 때만 본인 소유 ISO를 선택합니다. 일본어는 추가 언어팩이 없습니다.
진행률과 로그는 메인 화면에서 확인할 수 있습니다. 세이브는 공통입니다.

Choose a play language and press Play.
If updates are available, approve once: game update, selected language update, then automatic launch.
If current, Play starts immediately. Language selection alone never downloads anything.
Your own ISO is required for first setup. Original Japanese requires no extra pack.

プレイ言語を選んでプレイを押してください。
更新がある場合は一度確認し、承認後にゲーム更新・言語更新・起動まで自動で進みます。
初回準備時のみ原本ISOが必要です。日本語は追加パック不要です。

설정: %LOCALAPPDATA%\Macross30Launcher\settings.json

플레이 언어 옆에 설치 버전과 최신 버전을 표시합니다.

시작할 때 공개 릴리스에서 최신 정보를 직접 받습니다. GitHub API 인증이나 토큰이 필요하지 않습니다.
